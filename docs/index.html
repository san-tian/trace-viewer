skip_empty  （样本卡里显示为灰底「skip_empty」）
一句话：模型把 131,072 token 的预算全花在思考上，一个字答案都没写出来。 判分器拿不到可打分的正文，所以这个样本直接记 0 分，而且根本不调用 judge。

判据是什么：house 协议规定，judge 的打分对象是「第一个 </think> 之后的正文」。 如果文本里根本没有 </think>（思考没闭合），就等于「没开始答题」→ skip-empty → 0 分。

实测这 33 条的共性：finish_reason 全部是 length（打满上限被截断）、 completion_tokens 全部恰好 131,072、answer_text 0 字符、 思考文本 32.6 万～40.7 万字符，结尾是被切在半句话上。
